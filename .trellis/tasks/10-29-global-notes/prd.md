# T3 — Global Markdown Notes (Notion 式)

## Goal

提供 Notion 风格的全局 Markdown 笔记：一条笔记一个 `.md` 文件，存放在可配置的笔记库（默认 `$DSH_HOME/notes`）；在 Workspace 面板里以 `note` tab 打开，**单栏所见即所得**编辑（大标题 + 块式正文），笔记列表作为独立的 `notes` tab。跨工作区共享。

父任务：`10-29-workbench-plugin`（宿主路由与安全约定见父任务 `design.md`；设计稿 `lgBsZ` / 深色 `AfEbo`）。依赖 T1 的 `workbenchTabs` 注册契约。

## 实现前必须决

- 编辑器：**BlockNote**（用户指定，`@blocknote/shadcn`；只读态 `isEditable=false`）。
- 存储：BlockNote 的 markdown 导入/导出是 lossy（官方口径），无损需存 Block JSON，而 D4 要求「一条笔记一个 `.md`」。需在开工前选：(a) `.md` 为唯一正本、笔记只用受支持子集（推荐）；(b) 存 Block JSON；(c) `.md` + `.blocks.json` 缓存。

## Requirements

- **R3.1 笔记库定位与配置**：默认 `$DSH_HOME/notes`（不存在则首次使用时创建）；设置里可改为任意绝对目录（含 Obsidian 库）；路径校验拒绝相对路径与符号链接逃逸；切换库后列表与已打开 tab 需明确提示（不静默丢内容）。
- **R3.2 笔记列表（`notes` tab）**：列出库内所有 `.md`；显示标题、更新时间、摘要；支持按标题与正文检索、按最近更新/标题排序；`+` 菜单的 New note 直达新建。
- **R3.3 新建与命名**：新建即创建 `.md`（文件名来自标题 slug，冲突追加序号）；重命名同步文件名与 frontmatter 标题；删除需确认，删除后进 `.trash` 子目录而非直接抹除。
- **R3.4 编辑器（Notion 单栏所见即所得）**：顶部大标题（32px）+ 标签行；正文为块序列 —— 段落、待办（可勾选）、引用、代码块（带语言与复制）、分隔线；**不提供源码视图、不显示行号**；光标所在块显示左侧操作手柄（拖拽/菜单）。
- **R3.5 块编辑能力（v1 最小集）**：回车新建段落、`# ` / `- ` / `> ` / ` ``` ` 行首快捷转块、待办可勾选、代码块语言可切换；斜杠命令菜单与块拖拽排序作为 v1.1 增强项。
- **R3.6 保存与冲突**：自动保存（debounce 800ms）+ `Ctrl+S` 立即保存；显示保存状态（未保存/保存中/已保存/冲突）；外部修改时提示重载或覆盖，不静默覆盖。
- **R3.7 note tab**：作为 `note` tab 接入（`contentId: 'note:<relPath>'`）；同一笔记重复打开复用 tab；`dirty` 时关闭需确认；刷新后恢复打开过的笔记。
- **R3.8 frontmatter**：写入最小 frontmatter（`title`、`created`、`updated`、可选 `tags`），不覆盖用户已有未知字段与顺序。
- **R3.9 存储映射**：块序列与 `.md` 双向映射 —— 读取时把 Markdown 解析成块，保存时按块重新序列化；无法识别的块（如表格、脚注、HTML）以「原始 Markdown 块」只读展示并原样写回，不丢内容。

## Acceptance Criteria

- [ ] 首次打开笔记入口自动创建默认库并显示空状态与「新建笔记」按钮。
- [ ] 新建笔记、输入文字、等待自动保存后刷新：内容仍在，标题与文件名一致。
- [ ] 输入 `# ` 转标题、`- ` 转列表、` ``` ` 转代码块；勾选待办后保存，重新打开状态保持。
- [ ] 编辑过程中外部（如 Obsidian）修改同一文件：提示冲突；选择重载后内容变为外部版本，选择覆盖后写回本地版本。
- [ ] 含未知 frontmatter 字段与表格的既有 `.md`，打开后能显示（表格以原始块展示），保存后字段与表格内容不丢失。
- [ ] 笔记检索能按正文关键词命中并打开对应笔记。
- [ ] 在 A 工作区创建的笔记，切到 B 工作区仍能在笔记列表中打开同一内容。
- [ ] 设置里改库目录后列表正确切换，旧库文件未被删除或改动。
- [ ] 删除笔记后进入 `.trash`，列表不再显示，手动恢复后重新出现。

## Out of Scope

- 云同步、协作、评论、版本历史。
- Notion database/看板/表格视图、块级拖拽富文本（v1 只做段落/待办/引用/代码/分隔线）。
- 笔记内附件上传（图片沿用相对路径）。
- 全文索引服务（检索用文件扫描）。

## Dependencies / Risks

- 依赖 T1 的 tab 契约；Markdown 渲染器可直接复用 T1 的预览组件（块渲染与预览共用一套）。
- 块 ↔ Markdown 双向映射是最大技术风险：解析用 markdown-it AST，序列化用自写 renderer；遇到不支持的结构走「原始块」兜底。
- 与 Obsidian 共用目录时的写入冲突：以 mtime/etag 比较为准，宁可提示也不覆盖。
- 默认库在 `$DSH_HOME` 下，需确认宿主沙箱允许插件读写该目录（父任务 `design.md` 已列为约束）。
