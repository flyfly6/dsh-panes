# Workspace v0.3 — 笔记/配置/外壳与 tab 交互迭代

> 来源：`~/.dsh/notes/未命名笔记-2.md`（2026-11-04 最后更新）中记录的 20 条问题清单。
> 本任务只做规划，不写代码；`task.py start` 之前不动 `src/`。

## Goal

把 v0.1 可用版本暴露出来的「不顺手」逐条收掉：用户能自己调外观（字号/主题）而不改配置文件；笔记按项目隔离且名称到处置信；新建 tab / 会话 tab 的行为符合直觉；外壳（标题栏、侧栏、应用列表、项目按钮）不再有"点了没反应"的入口；资源管理器从"列表"变成"分栏 + 内部 tab"；移除无法救活的浏览器 tab；最后补图标与市场物料，把下一版发出去。

## 已确认事实（本轮核对代码，不是猜测）

- **字号其实已有配置项，只是没有入口**：`src/config.ts` 已声明 `fontUiFamily / fontUiSize / fontCodeFamily / fontCodeSize / fontCodeLineHeight`（`fontUiSize` 默认 0 = 用 CSS 默认值），样式侧读的是 `--wb-font-ui-size`（`src/styles/tailwind.css:38-39`）。缺的是让用户改到它、并保证组内所有面板立即生效。
- **状态栏明暗只是文本**：`src/panel/WorkbenchPanel.tsx` 状态栏尾部渲染 `Moon/Sun + t('status.dark'|'status.light')`，没有点击行为。
- **状态栏 running 数是会话条数**：同一文件 `project.sessionIds.length + t('status.running')`。它不是"正在跑的会话数"，这正是笔记对它的疑惑来源。
- **笔记侧没有项目维度**：`src/notes.ts` 的 `notes.*` op 表把全部笔记放在一个 vault 目录（`rel` 相对路径），没有 per-project 子目录；宿主已有 `notes.rename`（`src/notes.ts:341`，含原子写与冲突处理），所以"笔记 tab 不能重命名"是**客户端 tab 标题**的问题，不是文件层能力缺失。
- **浏览器 tab 是 iframe，且 webview 走不通**：`src/panel/BrowserView.tsx` 顶部注释记录了既有结论——桌面 `<webview>` 无法从客户端插件创建（S8）。本轮已从宿主包里拿到实证：主窗口 `webviewTag: true`，但 `will-attach-webview` 只放行内部租约，插件自建的 webview 一律被 `preventDefault`。详见 `research/browser-webview.md`。
- **添项目/新建项目当前必失败**：`src/client.tsx:122` 与 `WorkbenchPanel.tsx:425` 在客户端没有工作区注册 API 时直接抛 `sidebar.addProjectUnavailable`。这是 v0.2 PRD 已登记的遗留项。
- **既有 v0.2 任务只到 planning**：`.trellis/tasks/11-03-*`（Monaco/LSP/侧聊/恢复/tab 操作/git）全部 `status=planning`，无代码落地。本任务的「新建会话 tab」「滚动位置恢复」「tab 重命名」与其中 T4/T5 有交叠，见「依赖与顺序」。

## 需求分组（建议各自独立成子任务）

### A. 设置与外观

| 需求 | 现状 |
|---|---|
| 插件设置页：能改 UI 字号（12/13/14 或滑杆），对工作台全部面板即时生效 | 配置 schema 有字段，无 UI 入口 |
| 状态栏明暗标识可点击切换浅色/深色 | 现在是纯文本 |
| 状态栏计数改为「本项目已打开 tab 数」 | 现在显示的是 `project.sessionIds.length`（会话条数），语义错位 |

验收：改字号后无需重载插件，资源管理器/笔记/文件/会话 tab 的 UI 字号一起变（代码字号单独一项）；点状态栏明暗即切换并持久化；状态栏数字随 tab 开/关实时变化且等于本项目 tab 条数。

### B. 笔记模块

- 笔记页左侧操作按钮尺寸收敛到工作台密度尺子（22–26px 行、图标按钮 24px 级）。
- 笔记 tab 可重命名（改名走 `notes.rename`，非法字符/重名给出就地提示，不静默覆盖）。
- 同一份笔记在**列表 / tab 标题 / breadcrumb** 三处名称一致（以 frontmatter `title` 为准，缺省回退文件名）。
- 笔记按项目建立子目录存放，笔记列表按项目层级隔离（切换项目只看本项目笔记）。
- 支持把笔记移动到另一个项目（列表右键菜单 →「移动到项目…」），文件随之搬目录。
- 笔记条目右键/悬停菜单支持「在 Finder / 资源管理器中显示」（复用已有 `path.reveal`）。

验收：三处名称永远一致（重命名后立即一致）；切换项目后列表只剩本项目笔记且不丢旧笔记；移动后原项目不再出现、目标项目立即出现、链接/打开状态不指向失效路径；reveal 在 macOS 定位到 Finder 中的该文件。

### C. Tab 与会话行为

- 「新建会话 tab」是真新建：宿主建会话 → 挂进项目 → 客户端 retain 打开 tab，不加载上一个历史会话；下拉菜单新增「打开历史会话」。
- 同一会话只允许一个 tab（`contentId` 相同则聚焦已有 tab）。
- 切换回会话 tab 恢复上一次滚动位置（不回到顶部）。
- tab 支持上下 / 左右拆分布局与拖拽换位。

验收：新建会话 tab 首次渲染为空白新会话，且该会话在默认页面的项目会话列表里可见（同一个会话，不是第二份）；下拉菜单能打开任一历史会话；离开会话 tab 再回来滚动位置保持在 ±1 行内；拆分后两个 pane 各自独立滚动、拖拽后布局可恢复。

> 会话与 tab 的关系、宿主/客户端可用 API、以及"两处同时打开不冲突"的依据见 `research/session-tabs.md`。

### D. 外壳与导航

- 左上角「新建会话」与侧栏底部「应用」不再跳回 dsh 默认界面：应用在 tab 内打开，应用列表沿用默认界面的名称。
- 修好断头路入口：侧栏「添加项目」、下拉菜单「打开文件」「新建项目」要么可用，要么在 UI 上禁用并说明原因（不允许点了报错）。
- 左侧栏底部补头像 + 用户名 + 下拉菜单（对齐宿主侧栏）。
- 隐藏左上角的「切换侧栏」与「新建会话」两个按钮（用户已裁定，不隐藏整条标题栏）。
- macOS 双击标题栏最大化失效需要修复（窗口本身已是 `titleBarStyle: hiddenInset`，问题在自绘顶栏的拖拽区，不在窗口样式）。

验收：默认界面里的每个入口都能回到工作台对应 tab；断头路入口不存在（可用或明确禁用）；左上角两个按钮不出现；双击顶栏空白处能最大化/还原。

### E. 资源管理器

- 改为左右分栏：左树、右内容，文件在右侧**内部 tab** 打开。
- 视取舍去掉顶层「文件」tab 或保留为另一视角。
- 加「滚动到顶部 / 底部」悬浮按钮；文件树支持排序（名称/修改时间，目录优先）。

验收：打开文件不再新增顶层 tab；树滚动超过一屏后出现悬浮按钮且点击定位正确；排序切换后顺序可预期并持久化。

### F. 浏览器 tab（已调研，结论：移除）

调研已完成，结论是**普通插件无法使用 webview，本项直接移除**：宿主主窗口虽然开了 `webviewTag`，但装了一道租约闸门——`will-attach-webview` 只放行自己预发的 `about:blank#<lease>` guest，插件自建的 webview 一律 `preventDefault`；参考插件 `dsh-browser` 是靠往桌面安装目录装 bridge（改宿主）才驱动的。证据与复现命令见 `research/browser-webview.md`。

- 新建菜单去掉 `browser`；已有 `browser` tab 在启动恢复时静默丢弃并给一句提示。
- 地址栏入口保留为「在系统浏览器打开当前地址」。

验收：`browser` 不再出现在新建 tab 下拉；恢复含 browser tab 的旧布局不报错、不出现空面板。

### G. 品牌与发布

- 设计并落地插件图标（能在插件市场卡片上展示）。
- README 补截图/设计图与使用文档，发布下一版到 npm 与插件市场。

验收：图标在包内 `assets/` 且市场卡片可显示；README 含真实截图与安装/使用/配置三节；`npm publish` + 市场上架成功。

## 已裁定决策（2026-11-05 用户答复）

1. **新建会话 tab**：新建**空白**会话，不在默认页面额外多建一个会话；新会话挂进当前项目，因此会出现在默认页面的项目会话列表里——那是**同一个会话的两处视图**，不是两份。客户端 `retain` 是引用计数设计，两处同时打开不冲突（依据见 `research/session-tabs.md`）。下拉菜单新增「打开历史会话」。
2. **浏览器 tab**：webview 调研结论为不可行（普通插件被宿主租约闸门拦住），**移除该 tab**，改由「在系统浏览器打开」。证据见 `research/browser-webview.md`。
3. **macOS 标题栏**：隐藏左上角「切换侧栏」与「新建会话」两个按钮，保留标题栏；同时修双击最大化。
4. **状态栏计数**：改为「本项目已打开 tab 数」。
5. **笔记**：旧笔记按 frontmatter 项目字段归入，缺失的归入 `_inbox`；并新增「移动到其他项目」。
